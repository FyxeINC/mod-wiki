FFFoodSpoilageAndPreservation

Modrinth ↗Source ↗

Datapacks

Preservation is fully data driven. Datapacks can add modifier categories and modifiers, add smoker and campfire recipes that apply a modifier, and overlay the mod's food tags. The same files work on every supported version and loader. Use /reload after changing a datapack.

Modifier categories

Path: data/<namespace>/fffoodspoilageandpreservation/modifier_category/<id>.json (a synced registry).

{
  "priority": 0,
  "exclusive": true,
  "display_name": {"translate": "tooltip.fffoodspoilageandpreservation.category.preservation"}
}
Field Meaning
priority Higher categories rank first in tooltips and draw their tint in front
exclusive Only one modifier from this category can be on a food at once
display_name Text component shown in tooltips

Modifiers

Path: data/<namespace>/fffoodspoilageandpreservation/modifier/<id>.json (a synced registry). This is the built-in Candied modifier:

{
  "category": "fffoodspoilageandpreservation:preservation",
  "rate_multiplier": 0.40,
  "prevent_eating": false,
  "display_name": {"translate": "tooltip.fffoodspoilageandpreservation.modifier.candied"},
  "tooltip_color": "GOLD",
  "item_highlight": "tint",
  "item_tint": "#F2A21B",
  "apply_items": ["minecraft:honey_bottle"],
  "remove_items": [],
  "food_whitelist": [],
  "food_blacklist": ["#fffoodspoilageandpreservation:soups"],
  "auto_apply_when_cold": false,
  "auto_remove_when_warm": false
}
Field Meaning
category The modifier category this belongs to
rate_multiplier Multiplies the spoilage rate. Lower slows spoilage more
prevent_eating Food with this modifier can't be eaten (Frozen uses this)
display_name / tooltip_color Tooltip text and its color
item_highlight none (default), tint, outline or both, drawn in item_tint. Older files with tint_item: true and no item_highlight count as tint
item_tint #RRGGBB highlight color
apply_items / remove_items Items that apply or remove the modifier when crafted with food. Each entry may be an item, a #tag, or minecraft:potion#minecraft:awkward for a potion type
food_whitelist / food_blacklist A non-empty whitelist restricts which foods qualify; otherwise every spoilable food qualifies except the blacklist
auto_apply_when_cold / auto_remove_when_warm Temperature-driven modifiers like Frozen

Within a category, the modifier with the lowest rate_multiplier ranks highest. It wins when two modifiers share an apply item, and only a higher-ranked modifier replaces an existing one in an exclusive category. Modifiers no longer have their own priority; old files that still set it load fine and the value is ignored.

Built-in IDs: preservation, temperature (categories) and cured, brined, candied, dried, smoked, frozen (modifiers). Old saves with "cured" resolve to fffoodspoilageandpreservation:cured.

Cooking recipes

Smoker and campfire recipes keep the same food and apply a modifier:

{
  "type": "fffoodspoilageandpreservation:modifier_smoking",
  "modifier": "fffoodspoilageandpreservation:smoked",
  "cookingtime": 100,
  "experience": 0.1
}

Use "type": "fffoodspoilageandpreservation:modifier_smoking" for smokers and "type": "fffoodspoilageandpreservation:modifier_campfire" for campfires.

Item tags

You can overlay these item tags:

Tag Meaning
#fffoodspoilageandpreservation:never_spoil Foods that never spoil
#fffoodspoilageandpreservation:soups Soups (Candied skips them)
#fffoodspoilageandpreservation:smokable Cooked meat and fish the built-in Smoked modifier accepts (its food whitelist)
