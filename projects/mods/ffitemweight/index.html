FFItemWeight

Modrinth ↗Source ↗

Overview

Gives items weight and players configurable encumbrance bands.

Features

  • Counts item stacks and optional nested inventories.
  • Datapacks define item weights, capacity, and encumbrance levels.
  • Datapack weight_from references keep items equal to another item; all oxidized and waxed copper variants follow their matching fresh copper shape.

FFUtilities 0.2.8 is included in this mod JAR on every loader; no separate library download is needed.

How weight works

Every item has a unit weight. Stack weight is unit times count, plus the contents of shulkers, bundles and other nested inventories when that option is on. Your total is your inventory plus optional armor, offhand, Accessories and Curios slots.

Totals map to datapack encumbrance bands ordered by integer level. Capacity scaling can raise those capacities from player level, armor, equipment overrides, accessory bonuses and the Burden Bearing / Crushing Load enchantments.

Level Name Base capacity HUD shake Default effects
0 Unencumbered 200 off none
1 Light Load 500 off none
2 Medium Load 1000 off none
3 Heavy Load 2000 1.5 px slowness I, mining fatigue I
4 Overloaded 4000 2.0 px slowness III, mining fatigue I, weakness I
5 Immobile 999999 2.5 px slowness IV, mining fatigue II, weakness I, darkness

Bands can also list attribute modifiers (none shipped by default). Creative mode ignores carry weight unless you turn that on.

Weights are computed on the server (datapack bases plus optional recipe derivation) and synced; display is client-only. Items that hold other items through a loader storage API (a Forge or NeoForge item handler, or Fabric item storage on 1.21 and newer) have their contents counted too, as long as nested inventories are on.

Enchantments: Burden Bearing raises carrying capacity and Crushing Load (a treasure curse) lowers it. They are datapack enchantments on 1.21 and newer and built-in enchantments on 1.20.x, with the same levels and costs either way.

Client display

  • Tooltips: item weight category and numeric weight (Shift for precise values)
  • Inventory slots: optional outline or background by item weight band
  • HUD: icon from the band JSON, optional label (labelStyle: NONE / NORMAL / BOLD / UNDERLINE / OUTLINE) and total
  • Optional showWeightUntilNext draws 123.4 /2000 (+45)
  • Icon shake uses the band's shake field times the client intensity

Configuration

Client config: ffitemweight-client.toml (tooltips, slots, HUD). Server config: ffitemweight-server.toml (calculation, nested inventories, tracking, capacity, effect toggles). Encumbrance bands themselves are datapack JSON, not config. The config screens open from the Mods screen (through Mod Menu on Fabric). Forge 1.20.1 has no config screen, so edit the files there.

Recipe derivation settings live in the server calculation section; see Datapacks for how they interact with item weights.

Commands

Permission level 2:

  • /ffitemweight defaults [page] lists items still on defaultWeight.
  • /ffitemweight exportdefaults writes all those item IDs, one per line, to ffitemweight-defaults.txt in the current world's folder. Run it again after changing datapacks or mods to refresh the list.
  • /ffitemweight help lists commands.
