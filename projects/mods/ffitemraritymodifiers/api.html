Item Rarity Modifiers — Modding API

Entry point: com.fyxe.ffitemraritymodifiers.api.RarityModifierApi. Use it when your mod creates an item outside the built-in crafting, loot, or trade paths.

Roll a custom source

ResourceLocation source = ResourceLocation.fromNamespaceAndPath("mymod", "quest_reward");
boolean changed = RarityModifierApi.tryApplyRaritySource(
    reward, source, level.getRandom(), level.registryAccess());

The method takes an ItemStack, source ResourceLocation, RandomSource, and HolderLookup.Provider. It returns true when the stack changes. It is a safe no-op if the item is ineligible, already processed, has no matching source data, or fails its chance roll.

Pair code with data

Create data/mymod/ffitemraritymodifiers/rarity_source/quest_reward.json so pack authors can configure the source's chance and rarity weights. The source ID in code must match the namespace and file path. See the mod's README and shipped datapack files for the current schema.

Call from the logical server path that hands out the reward. Do not call repeatedly on the same stack in a tick; the API guards already processed items, but the best integration point is item creation.
