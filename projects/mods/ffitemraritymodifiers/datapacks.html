Datapacks

Datapacks control how often rarities appear and what their modifiers do. All files live under data/<namespace>/ffitemraritymodifiers/, and /reload picks up changes.

Folder What it controls
modifier_type/ One file per modifier: good or bad, which gear it fits, and what it changes
rarity_weights/<rarity>.json How many good and bad modifiers an item of that rarity rolls
rarity_source/<id>.json The chance a trigger rolls a rarity at all, and which rarity it picks
rarity_source_override/mob/ Sends specific mobs to a different rarity source
rarity_source_override/loot_table/ Sends specific loot tables to a different rarity source

Modifier types

{
  "category": "good",
  "kind": "attribute",
  "family": "attack_damage",
  "applies_to": ["weapon"],
  "required_item_tag": "c:tools/melee_weapon",
  "attribute": "minecraft:generic.attack_damage",
  "operation": "add_value",
  "slot": "mainhand",
  "base_value": 1.0,
  "value_per_rarity": {"common": 1.0, "uncommon": 1.5, "rare": 2.0, "epic": 3.0},
  "scales_with_rarity": true,
  "short_name": "ffitemraritymodifiers.modifier.attack_damage_up.short",
  "detailed_name": "ffitemraritymodifiers.modifier.attack_damage_up.detailed",
  "value_format": "%.1f"
}
Field Default Meaning
category required good or bad
kind required attribute (changes an attribute) or max_damage (changes durability)
family required Good and bad modifiers with the same family never appear together on one item
applies_to required Any of weapon, armor, tool, accessory
required_item_tag none Narrows the modifier to items in this tag, such as c:tools/fishing_rod
attribute / operation / slot none For attribute modifiers: the attribute ID, add_value / add_multiplied_base / add_multiplied_total, and the equipment slot group
base_value required The value when there is no per-rarity entry
value_per_rarity empty Values keyed by rarity
scales_with_rarity true Whether the value follows value_per_rarity
short_name / detailed_name required Translation keys for the normal and Shift tooltips
value_format %.1f How the number is printed

Attribute IDs follow the Minecraft version: on 1.21.11 write minecraft:attack_damage instead of minecraft:generic.attack_damage. Bundled examples include attack, armor, durability, reach, movement, health, mining speed, fishing luck and shield modifiers.

Rarity weights

File name must be a vanilla rarity ID (common, uncommon, rare, epic). Each list is a weighted table of how many modifiers to roll. This is the bundled rare.json:

{
  "good_amounts": [
    {"amount": 0, "weight": 0},
    {"amount": 1, "weight": 2},
    {"amount": 2, "weight": 2},
    {"amount": 3, "weight": 1}
  ],
  "bad_amounts": [
    {"amount": 0, "weight": 8},
    {"amount": 1, "weight": 2},
    {"amount": 2, "weight": 1}
  ]
}

Rarity sources

chance (0 to 1) is how likely the trigger rolls a rarity at all; rarity_weights picks which one, including Common. A successful Common roll is shown on the item.

{
  "chance": 1.00,
  "rarity_weights": [
    {"rarity": "common", "weight": 200},
    {"rarity": "uncommon", "weight": 50},
    {"rarity": "rare", "weight": 5},
    {"rarity": "epic", "weight": 1}
  ]
}

Built-in IDs used automatically: crafting, fishing, trading, mob_drops, loot_table. The bundled elite_mobs and dungeon_loot sources are used by the example overrides below. Packs that override trading_before must rename that source to trading. A smithing_default source also ships for future use, but nothing calls it automatically yet. Add your own ID and reference it from an override file or from a mod through the API.

Source overrides

Redirect specific mobs (or entity tags, with a # prefix) away from mob_drops, or specific loot tables away from loot_table:

{
  "targets": ["minecraft:wither_skeleton", "#minecraft:raiders"],
  "source": "ffitemraritymodifiers:elite_mobs"
}

Save it under rarity_source_override/mob/ for mobs or rarity_source_override/loot_table/ with loot table IDs as targets.

Item tags

data/ffitemraritymodifiers/tags/item/ holds weapons.json, armor.json, tools.json, mining_tools.json and accessories.json, which decide which single-stack items this mod may touch. Use tags/items (plural) on 1.20.6.

  • Weapons use the shared melee and ranged weapon tags (c:tools/melee_weapon and c:tools/ranged_weapon).
  • Armor uses #c:armors and includes elytra and wolf armor.
  • Tools use #c:tools (including rods, shears, brushes, igniters and shields) plus the two riding sticks.
  • mining_tools includes vanilla mining tools and shears, and takes priority over weapons so axes stay tools.
  • accessories is empty by default; add items or an accessory mod's own tags to opt them in.
