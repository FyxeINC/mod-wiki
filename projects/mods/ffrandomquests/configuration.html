Configuration

config/randomquests-common.toml:

  • hudShowTimer / hudCompactTimer: reset countdown on the HUD tracker
  • hudEnabled, offsets, scale, and the most tracked quests shown at once
  • showDaily / showWeekly / showMonthly / showShared / showMainGoal / showServerGoal: whether each category appears on the HUD tracker, the FFRandomQuests screen, or both
  • claimMode, playCompleteSound
  • Per-type enable flags and reward multipliers
  • Every dynamic difficulty factor, plus adaptive gain and loss

There is no datapack format; quest content, weights and generation come from this config.

Commands

Players:

/quests list | list shared
/quests info <id>
/quests claim <id>
/quests submit
/rq   (alias)

Operators (/quests debug ...):

complete <id> | completeall
progress <id> <amount>
generate <type> [period] [shared]
clear | refresh | claimall
types | dump | difficulty
adaptive reset | adaptive set <value>
give_rewards <id>
giveboard

/quests debug types lists the 24+ quest types (combat, gathering, crafting, exploration, social and survival).
