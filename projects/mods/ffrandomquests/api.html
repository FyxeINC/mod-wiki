Public API (for other mods)

Packages: com.randomquests.api

QuestTypeRegistry

Extend built-in quest generation and progress without replacing the mod.

Target lists (optional — registry scans already pick up most mod content)

QuestTypeRegistry.addKillTargets(ResourceLocation...);
QuestTypeRegistry.addCollectTargets(ResourceLocation...);
QuestTypeRegistry.addMineTargets(ResourceLocation...);
QuestTypeRegistry.addCraftTargets(ResourceLocation...);
QuestTypeRegistry.addBiomeTargets(ResourceLocation...);
QuestTypeRegistry.addEntityTargets(ResourceLocation...); // breed/tame

Custom generators

QuestTypeRegistry.registerCustomGenerator(QuestType.KILL, (player, level, period, shared, difficulty, random) -> {
    // return a Quest or null to fall back to built-in
});

Progress reporting & listeners

QuestTypeRegistry.reportProgress(player, QuestType.KILL, myEntityId, 1);
QuestTypeRegistry.addProgressListener((player, quest, amountAdded) -> { ... });
QuestTypeRegistry.addCompletionListener((player, quest) -> { ... });

MainGoalRegistry

MainGoalRegistry.registerPersonalGenerator((player, level, serverGoal, difficulty, random) -> {
    MainGoal g = new MainGoal(...);
    g.setTargetKey("mymod:boss_kills");
    return g;
});
MainGoalRegistry.reportCustomProgress(player, "mymod:boss_kills", 1);
MainGoalRegistry.addCompletionListener((player, goal) -> { ... });

Design note

Prefer relying on RegistryPools automatic scans. Use the explicit API when:

  • Your content is not discoverable by path/tag heuristics
  • You need a completely custom quest generator
  • You want to push progress from non-standard events

RewardRegistry

Other mods can register common/rare reward items, loot tables, and custom RewardProviders. See com.randomquests.api.RewardRegistry.

RewardRegistry

com.randomquests.api.RewardRegistry extends rewards. addCommonItems(ResourceLocation...), addRareItems(ResourceLocation...), and addLootTables(ResourceLocation...) add candidate IDs. registerProvider(RewardProvider) supplies custom rewards. The read-only getters expose registered candidates and providers. Register during setup, before quest rewards are generated.

RewardRegistry.addRareItems(ResourceLocation.fromNamespaceAndPath("mymod", "relic"));

Main goal and quest progress calls need a ServerPlayer. Use namespaced target keys for custom progress to avoid collisions with other mods.
