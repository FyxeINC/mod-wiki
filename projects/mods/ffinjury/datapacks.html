Datapacks

Injuries are not config lists. They load from datapacks (and other mods' data/ folders), and /reload picks up changes. Ship injury JSON on both sides when it comes from a mod, so clients get names and icons.

Injury files

data/<namespace>/ffinjury/injuries/<id>.json

Built-ins live under data/ffinjury/ffinjury/injuries/. The file bleeding.json in namespace ffinjury is ID bleeding; the file data/mymod/ffinjury/injuries/fracture.json is ID mymod:fracture.

Field Default Meaning
display_name prettified ID Title on the HUD, in commands and tooltips
description empty Extra inventory tooltip line
icon minecraft:paper Item drawn on the HUD
enabled true If false, not rolled from damage
treatable true If false, bandages skip it
heal_time_multiplier 1.0 Scales the global heal time for this injury
adrenaline_multiplier 1.0 Scales adrenaline when this injury is applied
damage_weights empty { damage_type, weight } entries for the damage roll
effects empty Potion effects while untreated
attributes empty Attribute modifiers while untreated

The max tier is shared by every injury: server config general.defaultMaxTier. It is not a per-injury field.

Effects use min_tier / max_tier (omit max or use 0 for no cap). scale_amplifier raises the amplifier by 1 per tier above the minimum (capped at 4).

Attributes use add_value, add_multiplied_base or add_multiplied_total. scale_amount grows the amount above min_tier. Write attribute IDs the way your Minecraft version names them (minecraft:generic.movement_speed up to 1.21.1, minecraft:movement_speed from 1.21.2); FFInjury accepts either spelling. An attribute the game version doesn't have is skipped.

Effects and attributes are suppressed during adrenaline or while that injury is treated.

Overriding a built-in

Ship the same path in a higher-priority datapack, for example <world>/datapacks/my_injuries/data/ffinjury/ffinjury/injuries/bleeding.json.

Damage chance

The chance that a hit injures you at all stays in the server config damage_sources.chances as damageTypeId;chance (for example minecraft:fall;0.12). Missing rows use defaultChance. An injury only rolls from a hit if it lists that damage type in damage_weights.

Hurt levels

The hurt level is your highest active injury tier. Rules for it are a separate datapack folder:

data/<namespace>/ffinjury/hurt_levels/<id>.json

Enable them with the server config hurt_level.enabled (off by default). Fields: min_hurt_level, stop_regen, regen_multiplier, effects, attributes. Matching rules combine.
