FFInjury

Modrinth ↗Source ↗

Overview

Adds tiered injuries, adrenaline, treatment, and healing.

Features

  • Injuries can worsen with repeated damage and respond to bandages.
  • Datapacks define injury types and optional hurt level rules.

FFUtilities 0.2.8 is included in this mod JAR on every loader; no separate library download is needed.

How injuries work

Taking damage can apply an injury. Each type has tiers. A new hit of the same type raises the tier instead of adding a duplicate. You can have several injuries at once; the default cap is three different injuries. At the cap, new types are ignored, but another hit can still worsen an existing type.

Adrenaline kicks in when you are injured. It hides injury debuffs for a short time that scales with the hit. When it wears off, untreated effects come back.

Bandages treat one untreated injury at a time (hold use). Treatment suppresses that injury's debuffs and can start a heal timer. Hold Shift on an injury icon in the inventory for remaining treat and heal times. If a treated injury has no heal timer at its tier, its tooltip says it needs sleep or a special heal.

Other healing:

  • Sleeping reduces a configurable number of tiers (higher tiers first).
  • An enchanted golden apple reduces every active injury by one tier.
  • Milk does not permanently clear injuries.
  • Tier 1 injuries recover passively. Higher tiers need treatment or sleep. Death clears injuries.

The HUD shows active injuries as item icons. Open your inventory for tooltips. Almost every layout, color and alert option is in the client config.

Creative: injuries are off unless you enable them, which also hides icons and skips healing and effects.

Default injuries: Twisted Ankle, Ankle Fracture, Broken Leg, Bruised Ribs, Broken Ribs, Concussion, Bleeding, Burn.

Commands

Operators (/ffinjury, permission 2 or higher): list, details, add, worsen, lessen, remove, clear.

Default balance

Injuries are short setbacks that leave you able to travel and fight. Built-ins use one percentage attribute penalty each, with no Wither, Weakness, Mining Fatigue, Slowness, nausea or blindness. Penalties stop growing at tier 3 even if a server raises the tier cap. Different injuries still combine multiplicatively.

Times are at zero XP, rounded to seconds, before the once-per-second healing check; XP speeds recovery. Tier 1 heals without treatment. Tiers 2 and 3 require treatment throughout each healing step. Global base times are 90 / 240 / 300 seconds, scaled by each injury's datapack multiplier.

Bandages suppress penalties for 45 / 90 / 120 / 240 seconds (improvised / standard / sterilized / cauterizing). Standard bandages cover every built-in tier 1 recovery. Sterilized bandages can heal a tier 2 twisted ankle, bruised ribs, bleeding or burn; cauterizing bandages cover one healing step for every built-in tier, including tier 3. Severe injuries can need a fresh bandage for the next step after treatment expires. Sleep heals two tiers, and Ethereal bandages remain an instant option.

Repeated environmental damage has especially low chances because each damage event rolls separately. Fractures have lower selection weights than minor injuries. Adrenaline starts at 15 seconds plus damage scaling, capped at 60 seconds. Optional hurt-level regeneration penalties are disabled by default.

Existing worlds: existing server config values are preserved when you update. To adopt new defaults, stop the world or server, back up <world>/serverconfig/ffinjury-server.toml, then remove that file so it regenerates (also check any defaultconfigs/ffinjury-server.toml template). This resets your custom server settings; alternatively copy only the changed values. Built-in injury JSON updates with the mod unless a higher-priority datapack overrides it.

Configuration

Damage chances live in the server config damage_sources.chances as damageTypeId;chance (for example minecraft:fall;0.12). Missing rows use defaultChance. An injury only rolls from a hit if it lists that damage type in its datapack damage_weights. The shared max tier is general.defaultMaxTier.

The in-game config screen exists on 1.21.1 and newer (on Fabric through Mod Menu); on older versions, edit the config file.

Injury types and hurt levels are datapack files; see Datapacks.
