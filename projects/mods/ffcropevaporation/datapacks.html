FFCropEvaporation

Modrinth ↗Source ↗

Datapacks

FFCropEvaporation reads two tags to decide which blocks count as farmland and which fluids can evaporate. Add your mod's farmland-like blocks or water-like fluids to them with a datapack (or your own mod's data/ folder). There are no other datapack options; everything else is in the config.

Tag Type Default contents
#ffcropevaporation:farmland block minecraft:farmland
#ffcropevaporation:evaporatable_water fluid #minecraft:water (still and flowing)

File locations

Minecraft Block tag Fluid tag
1.21 and newer data/ffcropevaporation/tags/block/farmland.json data/ffcropevaporation/tags/fluid/evaporatable_water.json
1.20.1 and 1.20.6 data/ffcropevaporation/tags/blocks/farmland.json data/ffcropevaporation/tags/fluids/evaporatable_water.json

Example

Let a modded farmland block count as farmland, keeping the default entries:

{
  "replace": false,
  "values": [
    "examplemod:rich_farmland"
  ]
}

Use /reload after changing a datapack.
