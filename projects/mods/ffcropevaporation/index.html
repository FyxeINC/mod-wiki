FF Crop Evaporation

Modrinth ↗Source ↗

Overview

Crop growth can consume nearby water and require water access.

Features

  • Configure evaporation chance, search radius, and weighted replacement blocks.
  • Optionally prevent growth when suitable water is absent.

FFUtilities is included in this mod JAR; no separate library download is needed.

How evaporation works

  • When a crop successfully grows, there is a chance that a nearby water block is replaced with a block picked from a weighted table.
  • Optionally (on by default), crops refuse to grow at all when no suitable water is found within range of their farmland.
  • Splash particles show when water is replaced.
  • Farmland and water are found through tags, so other mods and datapacks can opt in. See the Datapacks page.
  • Crop coverage: on NeoForge and Forge, any crop that fires the loader's crop-grow events. On Fabric, vanilla-style crops and stems (wheat, carrots, potatoes, beetroots, torchflowers, melons, pumpkins, and modded crops built on them).

Default behaviour

Setting Default Effect
Prevent dry growth On Crops will not grow if no water is found nearby
Require source for growth On Only full source water counts for the growth check
Replace mode SOURCE SOURCE = sources only, FLOWING = flowing only, BOTH = any water
Evaporate chance 15% Probability that a successful growth removes a water block
Search radius 6 Horizontal blocks searched around the farmland under the crop
Search Y min / max 0 / 1 Relative Y range (matches vanilla farmland hydration by default)
Replacement table Coarse dirt (5), Rooted dirt (5), Gravel (3), Moss block (1) Weighted random block used as the replacement

Biome temperature scaling

When enabled (default), the base evaporation chance is multiplied by a value based on biome temperature:

Region Approx. temp Default multiplier Effective chance (base 15%)
Snowy / frozen 0.0 or below 0.4x about 6%
Plains / forests about 0.7 to 0.8 about 0.9x about 13 to 14%
Desert / badlands 2.0 or above 1.75x about 26% (capped at 100%)

Temperatures between the cold and hot anchors are linearly interpolated. All values are configurable.

Configuration

All options live in the common config, shared between client and server: config/ffcropevaporation-common.toml, created on first run. You can also use the in-game config screen (the Mods list on NeoForge 1.21.1 and newer, or Mod Menu on Fabric 1.21.1 and newer). 1.20.1 and 1.20.6 have no in-game screen.

Weighted replacement table

Each entry uses the format "modid:block_name,weight". Higher weight means more likely to be chosen:

evaporateWeightedTable = [
    "minecraft:coarse_dirt,5",
    "minecraft:rooted_dirt,5",
    "minecraft:gravel,3",
    "minecraft:moss_block,1"
]
