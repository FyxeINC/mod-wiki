Configuration

Open the settings from the Mods screen (on Fabric, through Mod Menu), or edit the files directly. Dirt, damage, snow and cleaning are server rules in ffentitydirt-server.toml in the world's serverconfig folder, shared with players. Drips are your own settings in ffentitydirt-client.toml in the game's config folder.

Heights are fractions of the entity's height: 0 is the feet, 1 is the top of the head. Entity and block lists take IDs (minecraft:cow), tags (#minecraft:skeletons) or a whole mod (somemod:*). An empty whitelist means "everything", and the blacklist always wins.

Server: general

Option Default What it does
enabled true Master switch for everything
updateIntervalTicks 5 How often movement and water are checked
flushIntervalTicks 20 How often collected dirt is written into paint. Each write sends that mob's paint to nearby players
maxSplatsPerFlush 96 Cap on splats per mob per write
affectCreativePlayers true Whether creative players get dirt and marks (spectators never do)

Server: dirt (the Dirt layer)

Option Default What it does
enabled true Switch the Dirt layer on or off. Existing dirt still washes off
entityWhitelist / entityBlacklist empty / #ffentitydirt:never_dirty Which mobs can get dirty
surfaces.whitelist natural ground tags: #minecraft:dirt, sand, snow, base_stone_overworld, base_stone_nether, nylium, terracotta and #ffentitydirt:dirty_surfaces Which blocks leave dirt. Empty it to let every block leave dirt
surfaces.blacklist #ffentitydirt:clean_surfaces Blocks that never leave dirt, even if whitelisted
surfaces.colors grass, mud, podzol and friends; honey amber, slime green, sculk teal-black block=#RRGGBB dirt colors
surfaces.multipliers mud 3, clay, soul sand and sculk 1.5, dirt and sand 1.25, snow 0.75, stone, terracotta and end stone 0.4 to 0.5 block=number for how messy a block is. 0 means no dirt
surfaces.colorVariation 0.12 Random shading per splat
movement.minSpeed 0.3 Slowest speed (blocks per second) that picks up dirt
movement.splatsPerBlock 1.0 Average splats per block traveled at referenceSpeed (4.3, a walking player)
movement.speedExponent 1.5 How much faster movement boosts the rate
movement.baseReach / reachPerSpeed / maxReach 0.12 / 0.05 / 0.55 How high walking dirt can reach, growing with speed
movement.lowBias / opacity 2.5 / 0.35 Higher bias keeps dirt near the feet; strength of one splat
movement.spread 0.2 Each splat can fly up to this much higher than the reach. Raise it (and lower lowBias) to get dirt all the way up the body
movement.particles / particlesPerSplat true / 2 A puff of ground particles whenever walking leaves dirt, and how many per splat (up to 16 per puff)
fall.minDamage / splatsPerDamage 1 / 8 Least fall damage (half hearts) that splatters, and splats per half heart
fall.baseReach / reachPerDamage / maxReach 0.2 / 0.08 / 1.0 How high the splatter reaches
fall.lowBias / opacity 1.3 / 0.55 Spread and strength of fall splats
fall.spread 0.2 Extra random reach per fall splat
soot.enabled / color true / #1E1C1A Fire damage leaves soot, and its color
soot.strengthPerDamage 0.15 How quickly burning builds up soot
soot.bottomOpacity / topOpacity 0.8 / 0.15 Heaviest soot at the feet and at the top of the head, blending in between
blast.enabled true Explosion damage leaves soot (in soot.color) on the side facing the blast
blast.opacity 1.0 Soot strength from a blast right next to you. It fades to nothing at twice the blast's radius
blast.wrap 0.3 How far blast soot creeps around from the facing side: 0 stops at the sides, 1 reaches all the way around
sticky.enabled true Honey and slime blocks smear the feet in their color
sticky.blocks #ffentitydirt:sticky_surfaces Blocks that count as sticky; they leave no ordinary walking dirt. Colors come from surfaces.colors
sticky.splatsPerSecond / splatsPerBlock 1.5 / 3 Smears per second on a sticky block, standing or moving, plus extra per block moved (walking on dirt is about 1 per block)
sticky.reach / opacity 0.2 / 0.6 How high smears reach (feet and ankles) and how strong each one is
powderSnow.enabled / color true / #F2F6FA Powder snow coats whatever is sunk in it
powderSnow.buildPerSecond 0.12 How fast the coat builds, as the share of the way to a full coat per second
powderSnow.bottomOpacity / topOpacity / noise 0.85 / 0.6 / 0.3 Heaviest coat at the feet and at the snow's surface, and how patchy it is
lava.enabled / color true / #1A1210 Lava chars whatever is below its surface
lava.darkenPerSecond / opacity / noise 0.05 / 0.9 / 0.25 How fast it chars, the darkest it gets, and how patchy it is
lava.skipFireImmune true Leave naturally fire-immune mobs (striders, blazes, magma cubes) uncharred. Fire Resistance does not count
mining.enabled / chance / splats true / 0.3 / 3 Breaking a block can leave specks of its color; the chance per block and how many specks
mining.spreadDegrees / opacity 35 / 0.4 How far specks stray from the block's direction, and how strong each one is
mining.whitelist #minecraft:base_stone_overworld, #minecraft:dirt, #ffentitydirt:mining_blocks Blocks that leave specks. Empty it to let every block leave specks
mining.blacklist empty Blocks that never leave specks. Colors come from surfaces.colors, else the block's map color
appearance.brushMinRadius / brushMaxRadius 0 / 1 Each splat picks a random size between these, in texture pixels: 0 is a single pixel, 1 a small plus shape, bigger is a round blob
appearance.maxOpacity 0.85 Dirt stops building up at this opacity

Server: damage (the Damage layer)

Option Default What it does
enabled true Switch the Damage layer on or off. Existing marks still wash off
entityWhitelist / entityBlacklist empty / #ffentitydirt:never_damaged Which mobs get damage marks
minDamage 0.5 Least damage (half hearts) that leaves a mark
defaultColor #8A1C1C Mark color for mobs not listed below
colors endermen and ender dragon purple, #minecraft:skeletons brown, #minecraft:zombies darker red entity=#RRGGBB; an exact ID beats a tag
colorVariation / maxOpacity 0.08 / 0.95 Random shading; marks stop building up at this opacity
roughness 0.5 How messily wounds go on: samples wander and vary, edges come out ragged, stray droplets land nearby. 0 is perfectly clean
size.baseOpacity / opacityPerDamage 0.6 / 0.08 Mark strength: base plus a bit per half heart
size.baseRadius / radiusPerDamage / maxRadius 1 / 0.3 / 4 Mark size in texture pixels, growing with damage
projectiles.enabled true Projectiles mark where they hit
melee.enabled true Melee hits leave a wound
melee.aimFromEyes true Aim slashes along the attacker's line of sight from its eyes, so they land where it was looking. Off: the older placement on the side facing the attacker at a random height
melee.epicFightWeaponAim true With Epic Fight installed, aim a hit from one of its attack animations from the attacker's eyes through where the weapon was when it landed, so a low sweep marks the legs and an overhead blow the head. Off: Epic Fight hits are aimed like any other
melee.eyeSpread 0.12 How far a slash aimed from the eyes can land from where the attacker looked, as a fraction of the mob's height
melee.minHeight / maxHeight / sideSpread 0 / 1 / 0.4 With aimFromEyes off, where on the body the middle of a slash can land
melee.slashMinLength / slashMaxLength 1 / 4 Slash length in texture pixels: longest when the attacker is close. Every other wound shrinks by the same share of slashMaxLength, down to its own minimum; at 4 wounds are full size
melee.slashNearDistance / slashFarDistance 0.5 / 3 Attacker distance in blocks for the longest and shortest slash
melee.slashMinThickness / slashMaxThickness / slashThicknessPerDamage 1 / 3 / 0.3 Slash thickness in texture pixels, growing with damage. Odd widths only, so 2 rounds to 3. Other cutting wounds scale this; blots (stabs, bruises, crushes) scale size.baseRadius
wounds.enabled true Weapons leave their own wounds. Off: every melee hit is a slash and every projectile a puncture
wounds.weaponWound / unarmedWound / projectileWound slash / bruise / puncture Fallbacks: a weapon nothing else matched (attack damage or #c:tools/melee_weapon), a bare hand, non-weapon item or untagged mob, and an untagged projectile
wounds.betterCombatCategories every Better Combat preset category=wound for weapons Better Combat knows (dagger stabs, claymore cleaves, hammer crushes), used when the item is in no wound tag
wounds.epicFightCategories all 15 Epic Fight categories category=wound for weapons Epic Fight knows (dagger and spear stab, greatsword cleaves, longsword, tachi and uchigatana slash), used when the item is in no wound tag and has no Better Combat category. Epic Fight hits use the item that swung, so an off-hand weapon leaves its own wound
wounds.itemKeywords about 50 weapon words word=wound, matched against the item's ID as a last guess: sword matches iron_longsword, and the longest word wins, so pickaxe beats axe

Server: snow (the Snow layer; uses the dirt entity lists)

Option Default What it does
enabled true Switch the Snow layer on or off. Existing snow still melts and washes off
color #F4F8FF Snow color
buildPerSecond 0.02 How fast snow piles up. At the default, the top of the head is well covered after about a minute
depth 0.8 How far down from the top snow reaches. 1 goes all the way to the feet
topOpacity / bottomOpacity 0.9 / 0.1 Heaviest snow at the top and at the lowest point it reaches
noise 0.35 How patchy snow looks. 0 is a perfectly smooth fade
meltPerMinute 0.3 How fast snow melts once it stops falling on you. 0 keeps it until washed off

Option Default What it does

cleaning.water.fadePerSecond 0.1 How fast it washes off
cleaning.water.submergedOnly true Only wash what's under the water line
cleaning.water.waterlineMargin 0.05 A little splash above the water line
cleaning.rain.enabled / fadePerSecond true / 0.02 Rain from open sky washes the whole body, and how fast

Client: drips (particlePaint)

Option Default What it does
enabled true Drips paint mobs at all. Spots already painted keep fading while it's off
maxDistance 48 Only mobs this many blocks from your camera get painted or fade
maxChecksPerTick 4 How many mob models are checked for drip hits per tick. Lower is lighter on slow computers
hitsPerEntityPerSecond 4 Most drips painted on one mob per second
paintSelf true Whether drips paint you too
entityWhitelist / entityBlacklist empty / #ffentitydirt:never_dirty Which mobs drips paint
rules dripping and falling water (wet) and lava (scorch) Which particles paint, as particle=style. Add a mod's particles like somemod:falling_slime=wet, or a whole mod with somemod:*=wet
logHits false Log every drip that paints a mob
