FFUtilities

Modrinth ↗Source ↗

Overview

A shared API library for Fyxe mods on Fabric, NeoForge and Forge.

Features

  • Provides config, HUD, math, text, color, registry, weather, and soft compatibility helpers, plus wrappers for vanilla code that changed between Minecraft versions.
  • Lets Fyxe mods read Better Combat weapons, items worn in Accessories, Curios or Trinkets slots, and Cold Sweat temperatures, without needing those mods installed.
  • Fyxe mods include it through Jar-in-Jar, so players do not need a separate FFUtilities download.
  • It has no gameplay content by itself.
  • Config screen: the Mods list on NeoForge 1.21.1+ and Mod Menu on Fabric 1.21.1+.

Do I need to install it?

Usually not. Fyxe mods that use FFUtilities carry it inside their own jar, so it loads automatically. Install it by hand only when a mod's page asks for it. On Fabric it needs Fabric API; the config library it uses (Forge Config API Port) is already inside the jar.

Configuration

FFUtilities has one small common config, config/ffutilities-common.toml:

Option Default What it does
debug.debugLogging false Writes extra log lines about config entries that couldn't be read and optional mods that weren't found. Handy while tracking down a setup problem

You can also change it in game: the Mods list on NeoForge 1.21.1 and newer, or Mod Menu on Fabric 1.21.1 and newer.

FFUtilities has no datapack content. Datapack options belong to the Fyxe mods that use it.
