FFExpandedBiomeTint

Modrinth ↗CurseForge ↗Source ↗

Overview

Applies biome grass, foliage, or water tint to blocks selected by server datapacks or other mods. The bundled rules include stone and ores, vanilla deepslate and deepslate ores, clay, gravel, andesite, granite, tuff, calcite, and diorite. Deepslate uses 25% grass strength, while the other listed blocks use 45%. Common modded overworld ore names are covered by regex defaults.

Features

  • Choose blocks by exact ID, tag, or Java regex in datapacks or through the Java API.
  • Assign a channel and strength for each rule.
  • Tint block-breaking particles with the same biome color and strength as the block.
  • Sync server rules to clients on join and reload.
  • Works with Sodium on Fabric and NeoForge, and with Embeddium on Forge 1.20.1 and NeoForge 1.20.6.

See the Modding API for Java and datapack examples.

How the tint works

Install the mod on the server and every client. In singleplayer, install it in your client. Players need the mod on both sides to see server datapack rules.

The bundled rules tint stone, overworld base stone, all vanilla deepslate variants (including stairs, slabs, walls and the eight deepslate ores), the regular stone variants of those ores, plus clay, gravel, andesite, granite, tuff, calcite and diorite. Regex rules also cover common modded ore IDs ending in _ore or beginning with ore_. The default grass tint is 25% strength for deepslate and deepslate ores, and 45% for the other listed blocks.

Colors multiply the original texture, so its detail remains visible. Block-breaking particles use the same biome color and strength as the block. Inventory previews have no world biome to sample, so they are untinted.

When the rules arrive (on joining, or after /reload changes them), the client only rebuilds the loaded chunks; there is no resource reload screen.

Version differences

On Minecraft 1.21.11 and newer (including 26.x), and on 1.21.1 with Sodium, tinted blocks keep their random texture variants (such as stone's rotated textures). On the other versions and setups, each tinted block always shows the same variant. Everything else works the same on every version and loader.
