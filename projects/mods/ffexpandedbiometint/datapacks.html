Datapacks

Tint rules are JSON files in a datapack at:

data/<namespace>/ffexpandedbiometint/tint_rules/<name>.json

The server resolves the rules and sends the resulting block tints to clients when they join or when datapacks reload. Use /reload after changing a datapack. Players need the mod installed to see the tints.

Rule format

Each rule selects blocks with exactly one of:

Field Meaning
block An exact block ID, such as minecraft:clay
tag A block tag ID, written without #
regex A Java regular expression matched against the complete block ID, such as minecraft:stone

and sets:

Field Default Meaning
tint required grass, foliage or water
strength 1.0 From 0.0 (original texture) to 1.0 (full biome color) 
{
  "rules": [
    { "block": "minecraft:clay", "tint": "water", "strength": 0.35 },
    { "tag": "minecraft:base_stone_overworld", "tint": "grass", "strength": 0.45 },
    { "regex": "examplemod:.*_leaves", "tint": "foliage", "strength": 0.75 }
  ]
}

Rule order and overrides

The bundled defaults live at data/ffexpandedbiometint/ffexpandedbiometint/tint_rules/default.json. A datapack file at that same path replaces all bundled defaults. Otherwise, your files add to them: the bundled default file is applied first, then other files in resource ID order. Within a file, rules run top to bottom. The last matching rule sets a block's tint and strength, so you can override a broad tag or regex with a later exact block entry.

Rules registered by other mods through the API are defaults too; server datapacks can override them.

Built-in ore rules

The built-in regex rules cover IDs such as examplemod:tin_ore and examplemod:ore_tin at 45% strength, and names containing deepslate (such as examplemod:deepslate_tin_ore or examplemod:ore_deepslate_tin) at 25%. They skip the minecraft namespace and IDs containing common Nether or End material names (nether, netherrack, end_stone, endstone, the_end, basalt or blackstone). Block IDs alone can't identify every ore's dimension, so add a later rule or replace the defaults if a mod uses a different naming scheme.
