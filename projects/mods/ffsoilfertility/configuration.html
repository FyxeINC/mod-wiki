Configuration

Settings are split between a common file (gameplay, read by the server) and a client file, each grouped by topic. The mod has no commands.

Server options

File: config/ffsoilfertility-common.toml (a common config, not per world; the same path on every loader; use the config screen where available (NeoForge 1.21+ via FFUtilities, Fabric 1.21.1+ via Mod Menu; Forge 1.20.1 and 1.20.6 have none) or edit the file). Gameplay reads it on the server, whether dedicated or integrated. Clients do not read it: they receive the soil parameters from the server on login and on config reload.

The bone meal limit only applies to affected blocks (the ffsoilfertility:affected_blocks tag, plus every crop and stem block while growth.affectAllCropBlocks is on, all only while growth.affectCrops is on; saplings only while growth.affectSaplings is on) and only while enabled is true. By default only low quality soil is limited, to one stage per use; normal and high quality soil behave like vanilla. The cap applies whether the bone meal comes from a player or a dispenser. See Bone meal on the overview for which plants it affects.

Particles are sent from the server when an affected block grows, including growth from the extra ticks on faster soil. Sugar cane, cactus and bamboo count when they add a block above.

Climate: the soil noise is normalised (mean 0, standard deviation 1). Temperature and downfall each add influence * score to it, where the score is +1 at the ideal value and -1 at one tolerance away or more, falling off linearly in between. Only the biome's temperature and downfall are read, never biome ids, so modded biomes work. A factor is ignored unless temperatureEnabled or downfallEnabled is on (both are off by default), and influence 0 also disables it. With both factors enabled, the defaults make forest and plains-like climates fertile and deserts and frozen biomes poorer.

The percentages are approximate because they are quantiles of smooth noise. For example, soil.lowPercent = 30 with growth.lowGrowthMultiplier = 0 makes roughly a third of the land never grow affected crops.

Client options

File: config/ffsoilfertility-client.toml. These only change what you see: the grass colours (the world re-renders automatically when they change) and the hoe readout.

OptionDefaultRangeWhat it does
grassVisualstrueMaster switch for every grass colour change this mod makes. Off shows vanilla grass everywhere; the hoe readout still works. The tint.* options below set how grass looks while it is on.
tint.highSaturation0.30 to 1How much more saturated grass gets on high quality soil (0.3 is 30% more saturated).
tint.lowDesaturation0.40 to 1How much less saturated grass gets on low quality soil (0.4 is 40% less saturated).
tint.highHueShift4.0-180 to 180Hue shift in degrees for grass on high quality soil (positive moves green towards cyan).
tint.lowHueShift-6.0-180 to 180Hue shift in degrees for grass on low quality soil (negative moves green towards yellow).
tint.highBrightness0.03-1 to 1Brightness change for grass on high quality soil (0.05 is 5% brighter, -0.05 is 5% darker).
tint.lowBrightness-0.05-1 to 1Brightness change for grass on low quality soil.
tint.hoeReadouttrueWhile holding a hoe (either hand) and looking at a block, shows a coloured line above the action bar: "Soil: Low" (orange), "Soil: Normal" (white) or "Soil: High" (green). Only shown when the server has the mod.
