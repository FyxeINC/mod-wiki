FFSoilFertility

Modrinth ↗CurseForge ↗Source ↗

Datapacks

FFSoilFertility reads two block tags to decide which blocks grow faster or slower with soil quality. Add or remove blocks with a datapack (or your own mod's data/ folder). Everything else is in the config.

TagTypeDefault contents
#ffsoilfertility:affected_blocksblock#minecraft:crops, minecraft:sweet_berry_bush, minecraft:cocoa, minecraft:sugar_cane, minecraft:cactus, minecraft:bamboo, minecraft:bamboo_sapling
#ffsoilfertility:affected_saplingsblock#minecraft:saplings

File location

The files are data/ffsoilfertility/tags/block/affected_blocks.json and data/ffsoilfertility/tags/block/affected_saplings.json. On Minecraft 1.20.1 and 1.20.6 the folder is plural: tags/blocks/.

Example

Add a modded crop and keep the default entries:

{
  "replace": false,
  "values": [
    "examplemod:glow_wheat"
  ]
}

Set replace to true to drop the defaults and use only your own list. With the affectAllCropBlocks option on, blocks extending vanilla's crop or stem block are affected even if they are not in the tag. Use /reload after changing a datapack.

The affected_blocks tag only applies while the growth.affectCrops option is on. The affected_saplings tag works the same way but only while growth.affectSaplings is on (off by default). Every block extending vanilla's sapling block, including modded saplings, is affected without being listed; use the tag for modded saplings that do not extend it.
