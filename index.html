How the pieces fit together

LevelExample pathPurpose
Landing page/index.htmlOrientation and entry point — this page.
Project directory/projects/index.htmlLists every project as a card.
Project overview/projects/<name>/index.htmlOne page per project, summarizing status and links.
Project subpage/projects/<name>/<topic>.htmlDeeper docs — setup, architecture, decisions, etc.
Note

Search is powered by a small JSON-like index at assets/js/search-index.js. Add one entry per page you create and the search box picks it up automatically — no server required.
